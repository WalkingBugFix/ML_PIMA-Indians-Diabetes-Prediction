# ML_PIMA-Indians-Diabetes-Prediction
The objective of this study is to develop a predictive model that can accurately identify whether a Pima Indian woman is at risk of developing diabetes, based on diagnostic measurements such as glucose concentration, BMI, age, insulin level, blood pressure, and number of pregnancies.
